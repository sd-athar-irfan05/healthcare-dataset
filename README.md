# Healthcare Data Analysis

## Project Overview
This project focuses on analyzing healthcare data using Python and Pandas to extract meaningful insights from patient records.

## Objectives
- Explore and understand healthcare data.
- Analyze patient demographics.
- Study surgery types and operation duration.
- Analyze patient length of stay.
- Explore admission types.
- Practice data analysis using Pandas.

## Tools and Technologies
- Python
- Pandas
- Jupyter Notebook

## Project Files
- `healthcare_dataset.ipynb` - Jupyter Notebook containing the analysis.
- `healthcare_dataset.csv` - Dataset used for analysis.

## Key Skills
- Data Loading and Exploration
- Data Filtering
- Data Cleaning
- Data Aggregation
- Statistical Analysis
